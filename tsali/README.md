# Tsinadvneho’i Tsali Tsalagi

The Unit 3 (incompletive habitual) picture book: thirteen pages, each with its own narration clip, animated
illustrations and the words in syllabary, phonetics and English (toggle them with the buttons in the bar, or press T).
Illustrations: Shannon Whitelock and friends, © 2005 Indigenous Language Institute.

This is the 13 October 2026 version of the book, the same as the single-file `Tsali Tsalagi (standalone).html`
on Sara's Mac (Cher231 › Unit 3 - Incompletive Habitual › Tsalagi Tsalagi › Movie), split back into
`index.html` plus `img/`, `audio/` and `fonts/` so it can live on the shelf. It was made before the read-along
book skill, so it has its own player (no Time it mode); `pages.json` is a copy of the page text and
timings for reference, but `index.html` carries its own copy inline.
